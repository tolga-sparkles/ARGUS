NOTES

Data source
All pages read the same Health Engine snapshot — Overview, Servers, Alerts and Wall Mode always show identical results.
Security
Prometheus is only accessed by the backend. The browser never receives Prometheus URLs or credentials, and arbitrary PromQL / host / IP probing is not accepted.
Management Demo
Add ?demo=manager to any URL for the presentation dataset (16 demo servers, deterministic states: 12 healthy / 2 warning / 1 critical / 1 offline). It is a read-only simulation: no Prometheus calls, no incident persistence, no notifications — a permanent "DEMO · SIMULATED DATA" badge is shown.
