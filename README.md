# ARGUS paylaşım kopyası

Bu kopya kaynak kod incelemesi ve demo içindir. Gerçek envanter, veritabanları, ölçüm geçmişi, kimlik bilgileri, operasyon notları ve kuruma ait görseller dahil değildir.

## Demo

Python 3.10+ ile sanal ortam oluşturup `requirements.txt` bağımlılıklarını kurun. `.env.example` dosyasını `.env` olarak kopyalayın ve `SECRET_KEY` için rastgele bir değer belirleyin. Ardından `python app.py` çalıştırın. `DEMO_MODE=true` örnek veriler üretir.

Gerçek ortamda kullanmadan önce envanteri ve bağlantı ayarlarını kendi güvenli dağıtım sürecinizle sağlayın. Bu kopyada gerçek sunucu adresi veya e-posta bulunmaz.
